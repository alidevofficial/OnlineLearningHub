# 🎓 Online Learning Hub

A modern, responsive, and interactive educational landing page designed to streamline course registration, student inquiries, and direct communication.

🔗 **Live Demo:** [Online Learning Hub](http://alidevofficial.github.io/OnlineLearningHub/)

---

## ✨ Features

- **Responsive Design:** Optimized for mobile, tablet, and desktop screens with a clean dark/glassmorphic UI.
- **Course Registration Form:** Integrated with Google Forms and Google Sheets backend for seamless lead capture.
- **WhatsApp Integration:** Instant redirection to WhatsApp with pre-filled student details upon form submission.
- **Interactive Modals:** Quick inquiry and free quote modals.
- **Cross-Platform Support:** Universal email triggers supporting both mobile apps and desktop browsers.

---

## 🛠️ Built With

- **HTML5:** Semantic structure and responsive layout.
- **CSS3:** Modern flexbox/grid system, custom styling, and neon/glassmorphism UI accents.
- **JavaScript (ES6+):** Form handling, dynamic event listeners, and API endpoints integration.
- **Google Forms & Sheets:** Serverless backend for capturing and managing submissions.
